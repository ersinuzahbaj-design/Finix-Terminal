 
# ⚡ FINIX TERMINAL

### A Custom Python-Based Terminal for Windows

**Finix Terminal** — Python тілінде жасалған, Windows жүйесіне арналған жеке терминал жобасы. Ол қарапайым командалық интерфейс арқылы әртүрлі жүйелік функцияларды, желілік құралдарды және пайдалы утилиталарды бір жерге біріктіреді.

---

## ✨ Features

- 🖥️ **System Information** — компьютер туралы жүйелік ақпаратты көрсету.
- 📁 **File Management** — файлдар мен бумаларды қарау және басқару.
- 🌐 **Network Tools** — IP мекенжайын анықтау және Ping сұраныстарын орындау.
- 📷 **Camera** — камераны іске қосу.
- 📱 **QR Code Generator** — QR код жасау және сақтау.
- 📅 **Calendar** — күнтізбені терминал ішінде көрсету.
- 🎨 **Matrix Effect** — терминалға арналған Matrix стиліндегі анимация.
- 📝 **File Editor** — мәтіндік және код файлдарын өңдеу.
- 🌍 **Local Web Server** — жергілікті веб-серверді іске қосу.
- 📊 **System Monitoring** — жүйе туралы қосымша ақпарат алу.

## 📦 Installation

**1. Репозиторийді көшіріп алыңыз:**

```bash
git clone https://github.com/USERNAME/Finix-Terminal.git
```

**2. Жоба бумасына өтіңіз:**

```bash
cd Finix-Terminal
```

**3. Қажетті кітапханаларды орнатыңыз:**

```bash
pip install -r requirements.txt
```

**4. Терминалды іске қосыңыз:**

```bash
python Finix.py
```

## 💻 Requirements

- Windows 10 / Windows 11
- Python 3.10 немесе жаңарақ нұсқасы
